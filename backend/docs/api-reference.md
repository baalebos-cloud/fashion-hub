# API Reference

Full interactive reference is auto-generated by FastAPI at:

- Swagger UI: `GET /docs` (disabled when `APP_ENV=production`)
- ReDoc: `GET /redoc` (disabled when `APP_ENV=production`)
- Raw OpenAPI schema: `GET /openapi.json`

## Route modules

All routes live under `/api/v1` (see `app/api/v1/__init__.py` for the full
aggregation). Domain modules: `auth`, `users`, `customers`, `professionals`,
`tailors`, `designers`, `vendors`, `vendor_products`, `vendor_categories`,
`vendor_inventory`, `carts`, `checkout`, `orders`, `order_items`,
`order_timeline`, `payments`, `payment_webhooks`, `refunds`, `invoices`,
`receipts`, `payment_consent`, `deliveries`, `delivery_partners`,
`delivery_requests`, `delivery_tracking`, `delivery_webhooks`, `locations`,
`maps`, `geocoding`, `measurements`, `designs`, `categories`, `reviews`,
`ratings`, `notifications`, `messages`, `ai`, `ai_navigation`, `kyc`,
`kyb`, `search`, `favorites`, `dashboard`, `admin`.

## Fully implemented reference modules

- `auth.py` — complete signup/login/refresh/logout/verify/reset flow.
- `orders.py` — complete customer-order lifecycle matching the exact
  required endpoint surface (see [orders.md](./orders.md)).
- `payment_webhooks.py` — complete, signature-verified, idempotent webhook
  handling for Paystack and Flutterwave.

## Scaffold modules

All other route files contain a documented placeholder
(`GET /{prefix}/health-check`) confirming the router is wired into the
app, with a module-level docstring describing what belongs there and
which service to build against. Follow the pattern in `orders.py`: thin
route -> RBAC dependency -> one service call -> return.
